# 测试人员部署与运行指南

适用于第一次使用本项目的 Windows 测试人员。

GitHub 仓库：

```text
https://github.com/yingyingj936-creator/HarmonyOS-chujing-UI-Automation.git
```

## 1. 准备工具

电脑需要安装：

- Git
- Python 3.13
- PyCharm
- DevEco Studio 或 HarmonyOS SDK（提供 `hdc`）
- Java 和 Allure Commandline

安装后打开 PowerShell，确认以下命令都能显示版本号：

```powershell
git --version
python --version
hdc --version
java -version
allure --version
```

## 2. 下载并打开项目

1. 打开 PyCharm。
2. 点击 `Get from VCS`。
3. 填写仓库地址：

```text
https://github.com/yingyingj936-creator/HarmonyOS-chujing-UI-Automation.git
```

4. 选择保存位置，点击 `Clone`。
5. 项目打开后，在 PyCharm 下方打开 `Terminal`。

## 3. 安装项目环境

在 PyCharm Terminal 中依次执行：

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

看到 Terminal 左侧出现 `(.venv)` 表示环境已激活。

如果提示禁止运行脚本，先执行：

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
```

然后重新激活：

```powershell
.\.venv\Scripts\Activate.ps1
```

在 PyCharm 中将 Python 解释器设置为：

```text
.venv\Scripts\python.exe
```

设置位置：`File > Settings > Project > Python Interpreter`。

## 4. 配置并连接测试设备

使用 USB 数据线连接手机后执行：

```powershell
hdc list targets
```

正常情况下会显示 USB 设备序列号，例如：

```text
6HR0126106000329
```

`configs/default.toml` 默认配置为：

```toml
target_device = "auto"
```

电脑只连接一台 USB 设备时无需修改。连接多台设备时，将 `auto` 改成需要
使用的 USB 序列号。

运行前还需确认：

- 出境服务已经安装，已授权定位。
- 手机网络正常且未锁屏。
- 卡片没有新手引导(首页，多任务列表，编辑行程，游玩模式，行程详情页)
- 境外网络弹窗提示设为不在提醒， 最多开启八个服务弹出设为不在提醒
- 已添加卡片至桌面
- 应用默认目的地“中国香港”可用。
- 行程页新增“香港逛吃两日游”路线，“香港逛吃两日游”路线。收藏带“香港”字眼的帖子至少1篇。

## 5. 执行测试

每次重新打开 Terminal，先激活环境：

```powershell
.\.venv\Scripts\Activate.ps1
```

### 执行全部用例

```powershell
python -m pytest -s -q tests `
  --alluredir=reports/allure-results `
  --clean-alluredir
```

### 执行单个用例文件

把文件名替换成需要执行的用例：

```powershell
python -m pytest -s -q tests/test_home_first_screen.py `
  --alluredir=reports/allure-results `
  --clean-alluredir
```

测试期间不要操作、锁定或断开手机。

## 6. 查看测试报告

测试完成后执行：

```powershell
allure serve reports/allure-results
```

浏览器会打开 Allure 报告，可以查看：

- 成功和失败用例
- 测试步骤
- 错误信息
- 页面圈选截图

查看完成后，在 Terminal 按 `Ctrl+C` 关闭报告服务。

## 7. 清理运行文件

不需要每次手动清理。测试命令中的 `--clean-alluredir` 会清理旧报告。

报告异常时可以执行：

```powershell
Remove-Item -Recurse -Force .\reports, .\tmp_hypium -ErrorAction SilentlyContinue
```

该命令不会删除测试代码。

## 8. 获取最新代码

开始测试前，在 PyCharm 点击：

```text
Git > Pull
```

或在 Terminal 执行：

```powershell
git pull
python -m pip install -r requirements.txt
```

## 9. 常见问题

### 找不到 pytest

```powershell
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

### 找不到 hdc

将 HarmonyOS SDK 中 `hdc.exe` 所在目录加入 Windows `Path`，然后重新打开
PyCharm。

### USB 设备连接失败

检查 USB 数据线、USB 接口、设备调试开关和锁屏状态，再重新执行：

```powershell
hdc list targets
```

如果显示 `[Empty]`，说明电脑尚未识别设备。重新插拔数据线，并在手机上
确认 USB 调试授权。

### 报告打不开

确认 `allure --version` 能显示版本，然后重新执行：

```powershell
allure serve reports/allure-results
```

### 用例在 Setup 阶段失败

确认手机未锁屏、没有弹窗、网络正常，并手动回到出境服务首页后重试。

## 10. 日常操作顺序

1. `Git > Pull` 获取最新代码。
2. 激活 `.venv`。
3. 使用 USB 数据线连接设备。
4. 执行 `hdc list targets` 确认设备可见。
5. 执行单条或全量用例。
6. 使用 Allure 查看报告。
